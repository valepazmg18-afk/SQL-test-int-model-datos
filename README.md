# Prueba SQL

## Descripción

Este repositorio contiene la resolución de la prueba de SQL, desarrollada en PostgreSQL.

Cada requerimiento fue implementado siguiendo las instrucciones del enunciado y documentado mediante comentarios dentro del script SQL para facilitar su comprensión.

## Contenidos

* Creación de tablas con claves primarias y foráneas.
* Implementación de una relación muchos a muchos.
* Inserción de datos.
* Consultas utilizando `JOIN`, `LEFT JOIN`, `COUNT` y `GROUP BY`.
* Implementación de `ON DELETE CASCADE`.
* Restricción `CHECK`.
* Restricción `UNIQUE`.
* Modificación de tablas mediante `ALTER TABLE`.

## Tecnologías utilizadas

* PostgreSQL
* SQL
* Terminal `psql`
